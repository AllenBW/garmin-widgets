# garmin-widgets

Connect IQ (Monkey C) watch faces, glances/widgets and device apps for the
Garmin fēnix 8 Pro (454×454 AMOLED/MicroLED, non-solar).

## Ground rules

- **This project is completely self-contained.** It has nothing to do with
  Artisan (`AllenBW/artisan`) or any other repository. Don't add integrations
  with, references to, or code from other projects unless the owner asks for
  them explicitly.
- Target devices: `fenix8pro47mm` (fēnix 8 Pro 47 mm, 51 mm and MicroLED,
  454×454), `fenix847mm` (fēnix 8 47/51 mm, 454×454) and `fenix843mm` (fēnix 8
  43 mm, 416×416). All API 6.0.3, 128 KB watch face budget. Lay out relative
  to `dc.getWidth()` / `dc.getHeight()`, never fixed pixels, and build for all
  three before committing.
- Every watch face must respect the AMOLED always-on rules: at most 10 % of
  pixels lit, shift the layout each minute, and check `requiresBurnInProtection`.
  Use `Lib.Aod` for this rather than re-implementing it.
- Shared code goes in the `lib/` barrel as an annotated sub-module, and apps
  link only the annotations they use (see `apps/field/monkey.jungle`). Code
  that runs in a glance must carry `(:glance)`: `Fmt`, `Solar` and
  `Location` do, so glances may use them. When a watch face links one of
  those, monkeyc warns that the annotation is ignored; `scripts/build.sh`
  and `scripts/test.sh` drop exactly that line, so builds stay otherwise
  warning-free. Background services use no `Lib` at all (64 KB budget).
- Build with `scripts/build.sh <app>`; run `scripts/sim.sh <app>` to see it in
  the simulator; `scripts/test.sh <app> [device]` runs the unit tests in
  `apps/<app>/tests/` (annotated `(:test)`, excluded from normal builds). Add a
  test for anything new in `lib/`, and keep the draw-every-mode test passing.
  Check the Garmin API docs that ship with the SDK (`<sdk>/doc/Toybox/`)
  before using an API; don't rely on memory.
- Never commit developer keys (`*.der`, `*.pem`) or `bin/` output.
- The simulator is one process shared by every session and worktree on
  this Mac. Claim it by ID with `scripts/simlock.sh claim` (or `wait`)
  before loading anything into it, release it when done, and never load
  an app while another ID holds it. `test.sh` and `sim.sh` do this.

## Layout

- `EXPLORATION.md`: what the platform lets us do, with sources
- `designs/`: design specs and mockups (`DESIGNS.md`, `mockups.py` → `svg/`)
- `lib/`: the `Lib` Monkey Barrel shared by all apps (`Aod`, `Arcs`, `Fmt`, `Sun`, `Moon`, `Solar`, `Location`, `Sky`, `Cues`)
- `apps/<name>/`: one Connect IQ project per app (`apps/field/` is the Field
  watch face, design #1; `apps/battery/` the Battery Planner glance + app,
  design #2; `apps/daylight/` the Daylight sun-dial face, design #3;
  `apps/sunmoon/` the Sun and Moon glance + app, design #5; `apps/nightsky/`
  the Night Sky face, design #6, whose `Stars.mc` is generated by
  `designs/gen_stars.py`, never edited by hand; `apps/horizon/` the Horizon
  next-twelve-hours face, design #7; `apps/suncompass/` the Sun Compass
  glance + app, design #8; `apps/readiness/` the Readiness body-metrics
  face, design #4;
  `apps/sauna/` the Sauna and Steam glance + app, design #10, whose
  tracker and coach are pure arithmetic fed by the tests, whose plans
  per kind live in `resources/settings/`, and whose button cues sit at
  Garmin's own hint angles; `apps/sound/` the Sound Level glance + app,
  design #14, a watch-app because the microphone (`AudioInput`) is
  refused to widgets, whose meter maths and danger range are pure
  arithmetic in `SoundMeter.mc` fed by the tests, and whose cues come
  from `Lib.Cues` like the sauna's; `apps/forage/` the Forage beekeeper's
  face, design #15, whose bee rules and nectar year are pure arithmetic
  in `ForageModel.mc` fed by the tests)
- `scripts/watch.sh`: sideload to the fēnix 8 on the desk over MTP
  (libmtp) and pull its logs; the `mtp-*` commands need USB access, so
  run them outside the shell sandbox
- `scripts/`: build, simulator, test and store-package (`package.sh`) helpers; `docs/STORE.md` covers store submission
