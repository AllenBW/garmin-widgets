Watch Input Matrix

Every sensor and input a Connect IQ app can reach on the fēnix 8 Pro, by app type. Runs means a probe exercised it in the SDK 9.3.0 simulator on 29 Oct 2026; reported means a developer has seen it work on a real watch; docs means Garmin's docs allow it and nothing has tried it; refused means the compiler or the runtime said no. Sources: the SDK's API reference and Programmer's Guide, Garmin's Core Topics and FAQ, about forty developer-forum threads and public GitHub projects (reddit was unreachable). Nothing here has been run on our own watch yet. Tick a row once you have seen it on the wrist; ticks stay in this browser only.
