# The designs

Each face, glance and app began as a numbered design; the number is how
the code and the commit messages refer to it. The previews
(`preview_<app>.py`, Pillow) render a face with the sample readings the
screenshots use, and the generators (`gen_*.py`) write the tables and
fonts the code is built from; regenerate those, never edit them. The
design notes themselves, the research and the review rounds behind each
one, are not part of this repository.
